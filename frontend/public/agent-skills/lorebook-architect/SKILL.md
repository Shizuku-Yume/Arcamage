本技能帮你设计角色卡的世界书(`character_book`),作用于条目内容、关键词触发、以及插入策略。核心是「按需触发、信息分层、不冲突」——把背景设定从常驻的 `description` 里解放出来,只在相关时注入。

## 何时使用

- 用户想新增/扩充世界书背景(地点、势力、历史、规则、人物)。
- `description` 太长,想把背景设定拆出去按需触发。
- 现有世界书触发混乱:该触发不触发,或乱触发、信息打架。
- 用户想优化关键词、调整触发预算。

## 必须做

- 先用 `lorebook_*` 工具列出条目概览,**不要一次性读取整本世界书**。
- 用 `entry-design` 决定每条的内容写法、`constant` vs 关键词触发、`position`、`priority`。
- 用 `keyword-strategy` 选 `keys` / `secondary_keys`,规避误触发与触发冲突。
- 一条目一主题:每个条目聚焦一个概念,便于精准触发与维护。
- 新条目要与既有设定自洽,保留宏(`{{user}}`、`{{char}}`)与 HTML 标签。

## 不要做

- 不要把所有内容都设成 `constant`(常驻)——那等于没拆,白占预算。
- 不要用太宽泛的关键词(如「他」「城市」),会频繁误触发。
- 不要写超长条目;长背景拆成多条互相关联的小条目。
- 不要新增与卡片设定冲突的世界观事实。
- `constant=true` 的条目允许空 `keys`,不要因为 keys 为空就删掉它。

## 工作流

1. `lorebook_*` 列概览,确认已有条目与空白。
2. 按主题规划新条目(地点/势力/历史/规则/人物各自独立)。
3. 每条用 `entry-design` 定内容与插入参数,用 `keyword-strategy` 定触发词。
4. 检查关键词有无重叠冲突、是否会误触发。
5. 简述新增/调整了哪些条目及其触发逻辑。

## 示例

- 「把主角的家族背景做成世界书。」→ 拆成「家族概述(关键词:家族名)」+「家训规则」+「关键先祖」多条。
- 「世界观规则总是不生效。」→ 把核心规则设为 `constant=true` 常驻,细则用关键词触发。
