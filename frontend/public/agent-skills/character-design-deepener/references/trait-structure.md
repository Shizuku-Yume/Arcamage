# trait-structure

角色设定的结构化维度清单。不必每项都写满,但「动机」和「关系」几乎总是值得补。填写顺序建议从身份事实 → 性格内核 → 外在表现。

## 维度清单

### 1. 外貌(可被看见的)
- 整体印象一句话(身形、气质)。
- 1-2 个**标志性特征**(伤疤、异色瞳、总戴的某物),比逐项描述五官更有记忆点。
- 穿着风格 + 它透露的信息(职业、阶层、性格)。
- 写进 `description`。

### 2. 性格内核(驱动行为的)
- **核心欲望**:他最想要什么?(被认可 / 自由 / 复仇 / 安稳…)
- **核心恐惧**:他最怕失去/面对什么?
- **矛盾面**:表里不一之处(强硬外表下的软弱,温和下的偏执)。
- 这是立体感的来源,优先级最高。

### 3. 语气与说话习惯(可演绎的)
- 用词偏好(文雅/粗粝/夹术语/方言)、句长节奏。
- 口头禅、标志性称呼(怎么叫 {{user}})。
- 情绪激动 vs 平静时语气如何变化。
- 这些直接决定对话像不像本人,写进 `personality`,并与 `mes_example` 呼应。

### 4. 背景(解释「为什么是现在这样」)
- 关键经历:塑造了核心欲望/恐惧的那一两件事。
- 现状:身份、处境、当前目标。
- 背景信息量大时,放进世界书条目而非全塞 `description`(配合「世界书设计」技能)。

### 5. 动机与行为逻辑
- 在典型情境下他会怎么选(面对冲突 / 求助 / 诱惑)。
- 底线:什么事他绝不会做。
- 让模型有「依据」去演,而不是临场乱编。

### 6. 关系
- 与 {{user}} 的初始关系与张力(陌生/旧识/对立/暧昧)。
- 与世界里其他关键角色的关系(可放世界书)。
- 关系是剧情的引擎,几乎总该明确。

## 填写建议

- 每个维度优先给「具体细节」而非「抽象评价」。
- 一个好习惯:为核心欲望/恐惧各配一个能在场景里展现的具体行为。
- 外貌和背景容易写过量,克制;性格内核和动机容易被忽略,加厚。
