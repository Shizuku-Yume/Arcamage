# consistency-checklist

扩写或深化设定后的自检清单,防止「越改越乱」。重点抓矛盾、脸谱化、token 膨胀三类问题。

## 矛盾自检

逐项核对新增内容与既有设定是否冲突:

- [ ] **年龄/时间线**:经历的时长、年龄与外貌、事件先后是否自洽?
- [ ] **能力边界**:新写的能力有没有突破世界观设定的上限?有没有让角色变得无所不能?
- [ ] **世界观规则**:是否违反了卡片或世界书里已确立的规则(魔法体系、科技水平、社会结构)?
- [ ] **身份一致**:职业、阶层、立场前后是否一致?
- [ ] **语气一致**:`description`/`personality`/`first_mes`/`mes_example` 里的说话风格是不是同一个人?
- [ ] **关系一致**:与 {{user}} 及其他角色的关系描述有没有自相矛盾?

发现冲突时,优先改新增的那部分以迁就既有设定;除非用户明确要改设定。

## 脸谱化自检

- [ ] 性格是不是只有优点 / 只有缺点?有没有矛盾面与代价?
- [ ] 有没有「只贴标签不给行为」的描述?(把「她很冷漠」换成一个冷漠的具体表现)
- [ ] 角色有没有自己的欲望和底线,还是只是个工具人?
- [ ] 标志性特征是否够独特,还是随处可见的模板?

## Token 与密度自检

- [ ] 有没有为了凑字数重复表达同一个意思?
- [ ] 大段背景设定是不是更适合拆进世界书(按需触发)而非常驻 `description`?
- [ ] 删掉某句话会不会影响角色可演绎性?不影响就删。
- [ ] 整体篇幅与卡片复杂度匹配吗?(轻量陪聊卡不需要万字设定)

## 修订动作

- 局部问题用 `card_patch_text` 小改,不要整段重写。
- 背景信息超量 → 迁移到世界书条目(配合「世界书设计」技能)。
- 改完保留所有宏(`{{user}}`、`{{char}}`)与 HTML 标签,并简述改了什么。
