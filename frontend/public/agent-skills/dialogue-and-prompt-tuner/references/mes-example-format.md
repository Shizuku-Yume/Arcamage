# mes-example-format

`mes_example` 的格式与写法。它的作用是给模型「角色怎么说话」的范本——靠模仿,而不是靠告知。

## `<START>` 约定

`<START>` 用来标记一段示例对话的开始。多段示例各用一个 `<START>` 分隔,每段是一轮或几轮的来回。

```
<START>
{{user}}: 你这药……真的有用?
{{char}}: 「用?」她嗤笑一声,把瓷瓶丢进你怀里,「死马当活马医的玩意儿,要不要随你。」

<START>
{{user}}: 谢谢你救了我。
{{char}}: 她别开脸,耳尖却红了:「少废话,欠的命下次记得还。」
```

## 写法要点

- **示范语气,不是复述设定**:展示用词、句式、情绪反应、肢体小动作,而不是把人设再讲一遍。
- **用 `{{user}}` 和 `{{char}}`**:别写死具体名字,保持可移植。
- **覆盖典型情境**:挑 2-3 个最能体现性格的场景——日常互动、被触及核心话题、冲突/被冒犯时的反应。
- **长度适中**:每段几轮即可,示例是「样本」不是「剧本」。
- **风格一致**:示例里的语气必须和 `personality`、`first_mes` 是同一个人。

## 对话之外的描写

- 可以带少量动作/神态描写(夹在台词里),示范叙述风格。
- 但不要替 {{user}} 写台词以外的既定心理或动作——保持玩家的能动性。

## 与 personality 的分工

- `personality`:**告诉**模型角色是怎样的(抽象特质)。
- `mes_example`:**展示**这些特质在对话里长什么样(具体样本)。
- 两者要一致:若 personality 说「毒舌」,示例就得真的毒舌。
